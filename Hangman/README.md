# Hangman Game

This is a classic Hangman game developed as part of the "100 Days of Code: The Complete Python Pro Bootcamp". The project focuses on string manipulation, list management, and the implementation of game state logic.

## Getting Started

The game relies on external modules for its word database and visual art. Ensure all project files are in the same directory.

### Prerequisites
* Python 3.x installed.
* Files required: `hangman_words.py` (word list) and `hangman_art.py` (ASCII art).

### How to Run
To start the game, navigate to the project folder and run:

```bash
python3 main.py
