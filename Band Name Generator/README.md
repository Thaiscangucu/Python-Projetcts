# Band Name Generator

A simple and fun Python application developed during the **100 Days of Code: The Complete Python Pro Bootcamp**. This program generates a creative band name by combining a city name and a pet's name based on user input.

## Getting Started

This project is a standalone script designed to be executed directly from the terminal.

### Prerequisites
* **Python 3.x** installed.

### How to Run
To start the generator, navigate to the project folder and run the following command in your terminal:

```bash
python3 main.py
