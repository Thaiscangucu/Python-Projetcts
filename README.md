# 🐍 100 Days of Code: The Complete Python Pro Bootcamp

This repository contains a selection of projects I developed during the "100 Days of Code" Udemy course. Rather than listing every daily exercise, this portfolio focuses on the applications that best demonstrate my growth in programming logic, automation, and interface development.

## 🚀 Technologies Used

* **Language:** Python 3.x
* **Main Libraries:** Tkinter (GUI), Pandas (Data Analysis), BeautifulSoup4 (Web Scraping), Selenium (Automation), Flask (Web Development), Turtle (Graphics).
* **Core Concepts:** Object-Oriented Programming (OOP), File Handling, REST APIs, Error Handling, and List/Dict Comprehension.

---

## 🏆 Project Highlights

Below are the projects I consider the most important milestones of this journey:

### 🎮 Games and Interfaces (GUI)
* **Pong & Breakout Games:** Classic implementations using the `Turtle` library, focusing on collision detection, state management, and movement logic.
* **Turtle Crossing:** A "Frogger" style game utilizing OOP to manage procedural car generation and progressive difficulty levels.
* **Pomodoro Timer:** A productivity app built with `Tkinter`, featuring countdown mechanisms and a dynamic user interface.

### 📊 Automation and Data
* **U.S. States Game:** An interactive quiz using `Pandas` to read geographical data from a CSV and map user answers in real-time on the screen.
* **Amazon Price Tracker:** A bot that performs Web Scraping to monitor product prices and sends email alerts when the value hits a target price.
* **Stock News Alert:** Integration of multiple APIs (Alpha Vantage and NewsAPI) to monitor stock market fluctuations and send SMS messages via Twilio with the day's top headlines.

### 🌐 Web and APIs
* **Flight Search Engine:** A flight search tool that uses aviation APIs to find the best deals and manages search data through Google Sheets.
* **Top 10 Movies Website:** A web application developed with `Flask` and `SQLite`, integrated with the TMDB API to list, edit, and rate favorite movies.
