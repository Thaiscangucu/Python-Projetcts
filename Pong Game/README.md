# Pong Game

A classic arcade game implementation developed as part of the "100 Days of Code: The Complete Python Pro Bootcamp". This project focuses on Object-Oriented Programming (OOP) to manage real-time movement, collision detection, and multi-module synchronization using the Turtle graphics library.

## Getting Started

This project is modularized into several classes. Ensure all component files (paddles.py, ball.py, and score.py) are in the same directory as main.py.

### Prerequisites
* Python 3.x installed.

### How to Run
To start the game, navigate to the project folder and run:

```bash
python3 main.py
