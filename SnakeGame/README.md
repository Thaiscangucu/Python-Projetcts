# Snake Game

A modern implementation of the classic Snake game developed during the "100 Days of Code: The Complete Python Pro Bootcamp". This project emphasizes Object-Oriented Programming (OOP) to manage game entities, collision logic, and persistent high scores.

## Getting Started

This project is modularized into several specialized classes. Ensure that snake.py, food.py, and score.py are present in the same directory as main.py.

### Prerequisites
* Python 3.x installed.

### How to Run
To start the game, navigate to the project folder and run:

```bash
python3 main.py
