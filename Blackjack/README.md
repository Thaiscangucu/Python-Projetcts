# Blackjack Game

A terminal-based version of the classic card game Blackjack, developed as part of the **100 Days of Code: The Complete Python Pro Bootcamp**. This project implements game logic, score calculation rules (including Ace's behavior), and an automated dealer opponent.

## Getting Started

This project is a standalone script designed to be executed directly from the terminal.

### Prerequisites
* **Python 3.x** installed.
* Ensure the `art.py` file (containing the logo) is in the same directory as `main.py`.

### How to Run
To start the game, navigate to the project folder and run the following command in your terminal:

```bash
python3 main.py
