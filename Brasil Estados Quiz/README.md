# Estados do Brasil Quiz

An educational and interactive game developed as part of the **100 Days of Code: The Complete Python Pro Bootcamp**. This project challenges users to name all 26 Brazilian states and the Federal District on a map, utilizing data handling and graphical coordinates.

## Getting Started

This project requires external data files (`estados.csv` and `mapa_brasil2.gif`) to function correctly.

### Prerequisites
* **Python 3.x** installed.
* **Pandas** library installed:
